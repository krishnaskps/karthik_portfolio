# Karthikeyan Keppanan — Personal Portfolio

A modern, responsive, and performance-optimized personal portfolio built for **Karthikeyan Keppanan**, Senior Software Engineer with 9+ years of enterprise experience across Banking/FinTech, Healthcare EHR, Education, and Government sectors.

## Tech Stack

- **Framework**: React.js 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Custom SVG icons
- **Animations**: Framer Motion & CSS keyframes
- **Effects**: canvas-confetti (interactive contact feedback)
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)
